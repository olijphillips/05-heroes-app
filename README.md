# Heroes APP

## Levantar desarrollo

1. Clonar el repositorio
2. Editar el archivo `.env` con las varaibles de entorno
3. Ejecutar `npm install`
4. Ejecutar `npm run dev`
5. Levantar el backend

Para levantar el Backend en el folder del Backend
$env:PORT=3001; npm run start:dev

$env:PORT=3000; npm run start:dev

Cambie el puerto a discrecion
